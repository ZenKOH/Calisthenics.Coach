# Contributing

## Exercise content

Every exercise must include:

- unique ID and slug;
- movement family;
- difficulty and impact;
- equipment tier;
- prescription type and target;
- four instruction steps;
- four demonstration phases;
- coaching cues and common errors;
- safety notes;
- valid progression, regression and substitution IDs.

Run `npm run check` before opening a pull request.

## Claims

Do not add medical, diagnostic, injury-prevention or automatic-detection claims without documented validation and review.
